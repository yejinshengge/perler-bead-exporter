# 拼豆图纸导出工具 - Aseprite 插件

为 Aseprite 提供颜色名称显示和拼豆图纸导出功能，帮助你轻松制作像素画拼豆作品。

## ✨ 主要功能

### 📌 功能 1：实时显示颜色名称

在绘制过程中实时显示当前选中颜色的名称，支持 GPL 调色板文件。

**特点：**
- 🎨 浮动窗口实时显示颜色信息
- 🔄 自动匹配 GPL 调色板颜色名称
- 💾 支持自动加载同名 GPL 文件

### 🎯 功能 2：导出拼豆图纸

将像素画导出为专业的 HTML 格式拼豆图纸，包含网格、颜色标注和统计信息。

**特点：**
- 📊 完整的颜色统计表（数量、占比）
- 🎨 可自定义网格大小和字体
- 📝 显示颜色名称、HEX 代码和坐标
- 🌐 HTML 格式，可在浏览器中查看和打印

## 📥 安装方法

1. 将整个 `perler-bead-exporter` 文件夹复制到 Aseprite 插件目录：
   - **macOS**: `~/Library/Application Support/Aseprite/extensions/`
   - **Windows**: `C:\Users\[用户名]\AppData\Roaming\Aseprite\extensions\`
   - **Linux**: `~/.config/aseprite/extensions/`

2. 重启 Aseprite

## 🚀 使用指南

### 步骤 1：准备 GPL 调色板文件

GPL 文件是 GIMP 调色板格式，用于定义颜色名称。

**文件格式示例：**
```
GIMP Palette
Name: 我的拼豆调色板
#
255 0 0 红色
0 255 0 绿色
0 0 255 蓝色
255 255 0 黄色
```
将调色板文件加载到Aseprite

### 步骤 2：显示颜色名称窗口

1. 点击菜单 `视图` → `拼豆图纸导出工具`
2. 首次使用时，选择 GPL 调色板文件
3. 浮动窗口会显示：
   - 🎨 当前选中颜色的色块
   - 📝 颜色名称（从 GPL 文件匹配）
   - 🔄 实时更新（每 100ms）

**窗口功能按钮：**
- **导出图纸**：快速导出 HTML 图纸
- **重新加载**：更换 GPL 调色板文件

### 步骤 3：导出拼豆图纸

1. 在颜色名称窗口中点击 **导出图纸** 按钮
   
2. 配置导出参数：
   - **网格大小**：单元格像素大小（推荐 40px）
   - **显示颜色名称**：在每个格子中显示颜色名称
   - **显示颜色代码**：显示 HEX 颜色代码
   - **显示坐标**：显示行列坐标
   - **字体大小**：单元格文字大小（推荐 10px）

3. 选择保存路径（HTML 文件）

4. 点击 **导出**

**注意：绘图使用的画板必须与加载的画板一致，否则会出现名字未定义或错误的情况**

**导出内容包括：**
- ✅ 带网格的像素图
- ✅ 每个单元格显示颜色名称和代码
- ✅ 完整的颜色统计表
- ✅ 摘要信息（尺寸、总像素数、颜色种类）
